# 🏠 Kostify

> Platform marketplace jasa untuk anak kos dan perantau

## Deskripsi
Kostify adalah aplikasi web yang siap jadi andalan anak kos. Di sini, kamu bisa nemuin berbagai layanan seperti laundry baju hingga sepatu, isi galon, print dan foto copy, cleaning kos, sampai jasa pindahan, semua dalam satu tempat. Pengen hidup praktis anti ribet?Kostify-in aja!

## Fitur
- 🔍 Pencarian jasa terdekat berdasarkan lokasi kos
- 🧺 5 kategori layanan utama
- 💳 6 metode pembayaran (Cash, OVO, GoPay, ShopeePay, DANA, Transfer)
- 📍 Tampilan hasil mitra terdekat
- ✅ Alur pemesanan lengkap dengan ringkasan biaya

## Teknologi
- HTML5, CSS3, JavaScript (Vanilla)
- Hosted via GitHub Pages
